# KorSDC 워크샵
(KorSDC Workshop)

## KorSDC 번개 워크샵 (KorSDC Lightning Workshop)

SDC3(SKA Science Data Challenge)를 진행 중인 KorSDC에서 자체 워크샵을 개최합니다. KorSDC의 현재 진행 상황을 공유하고, 토론 위주의 워크샵을 통하여 SDC3를 성공적으로 수행하는 발판을 마련하고자 합니다. 예향의 도시 광주에서 5월 24일(수) - 25일(목)에 걸쳐 개최됩니다.

## 일정 (Schedule)

첫째날(5월 24일 수요일)

시간 [사회자]: 주제 (발표자)

                  - 12:00 - 1:15: lunch
                  - 1:15 - 2:00 [안경진]: SDC progress report / HPC usage instruction (안경진, [slide](https://drive.google.com/file/d/187bXf_Qv8M2Zguy4gUgAdbquPXZKijdP/view?usp=share_link))
                  - 2:00 - 2:45 [손봉원]: data cleaning -- primary beam correction & point source removal (김민수, [slide](https://drive.google.com/file/d/1-3nOsz0Oj8GWCS7SEDzU-fAdMcmfjCOz/view?usp=share_link))
                  - 2:45 - 3:30: coffee break / free discussion
                  - 3:30 - 4:15 [David Parkinson]: foreground removal algorithms (David Parkinson, [slide](https://drive.google.com/file/d/1n2BXPsLMOLX03MPU9DLNeI3Cuqpexw91/view?usp=sharing))
                  - 4:15 - 5:00 [안경진]: to-do's and task assignment (안경진, [slide](https://drive.google.com/file/d/1cIFCKSI0NZ8t0NRTdKqpvuDxQORvV-ku/view?usp=share_link))
                  - 5:30 - 6:30: dinner

둘째날(5월 25일 목요일)

                  - 9:00 - 10:30: SKA science assessment
                  - 10:30 - 12:00: Free discussion
