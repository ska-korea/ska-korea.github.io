*[SKA data challenge 실습 대비 준비사항]

1. 실습은 개인 노트북을 사용하여 진행됩니다.

2. 계산 환경: 개인 노트북에 아래 python 기반 컴퓨팅/에디팅 환경이 준비되어야 가능합니다.

- python3

- jupyter notebook

- numpy

- scipy

- powerbox

- healpy

- scikit-learn

- 옵션(없어도 실습 가능): pyGDSM ([https://github.com/telegraphic/pygdsm](https://github.com/telegraphic/pygdsm))

설치(pygdsm 설치 디렉터리에서 setup.py 사용) 후 첨부 ipynb 화일 jupyter notebook에서 실행

(실행하면 자동으로 NASA에서 제공하는 Milky Way 전파 data(총 ~1GB)를 cache로 다운받음.)

- 옵션의 첨부 ipynb 화일: https://drive.google.com/file/d/153yw9lBV8QKXguiBp45SPwwPmtjejIrl/view?usp=sharing

3. 실습용 mock data: [https://drive.google.com/drive/folders/1v6BRJ4Tkh9cm5HDfDPD_tfXGoO4Oi9lr?usp=share_link](https://drive.google.com/drive/folders/1v6BRJ4Tkh9cm5HDfDPD_tfXGoO4Oi9lr?usp=share_link)

실습하실 분들은 링크의 세 개의 파일을 받으면 됩니다.
